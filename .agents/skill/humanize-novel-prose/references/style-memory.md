# 文风记忆

这个文件是活文档。

用途：

- 记录已被样文或既有章节反复证明的风格规律
- 记录容易破坏“人味”和项目 voice 的负向规则
- 在多次会话之间累积可复用的文风判断

更新原则：

- 只写高复用价值的观察
- 结论尽量短、可执行
- 推测与已确认内容分开
- 新项目单开分区，不覆盖旧项目

## 通用去 AI 味记忆

### 已确认

- 优先减少解释腔、总结腔和一次性说透的句子。
- 优先让情绪落到动作、停顿、感官和选择上。
- 优先保留局部毛边，不把所有句子抛光成同一种圆滑质感。

### 负向规则

- 避免万能情绪判断直接盖章。
- 避免段尾突然升华。
- 避免对白像在替作者做说明。

### 待验证

- 暂无。
