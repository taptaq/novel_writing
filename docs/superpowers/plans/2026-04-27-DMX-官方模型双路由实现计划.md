# DMX 与官方模型双路由 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `Kimi`、`GLM`、`Qwen` 增加 `DMX -> 官方 -> 系统兜底` 的双路由，为 `DeepSeek` 保持 `官方 -> 系统兜底`，同时不改变前端模型按钮结构。

**Architecture:** 在现有 `env -> providers -> router -> route/component` 链路上增强 provider 描述能力，让同一个 `selection` 支持多个候选上游。手动模式按模型内部优先级重试，自动模式按全局优先级遍历，并继续返回最终命中的 provider/meta。

**Tech Stack:** Next.js 14、TypeScript、Vitest、Zod、OpenAI-compatible HTTP chat completions

---

- [ ] **Step 2: 调整 router，让手动模式也支持多 provider 重试**

把 `src/lib/ai/router.ts` 的候选序列逻辑改成：

```ts
const providers = getOrderedProviders();

function sortByPriority(candidates: ModelProvider[]) {
  return [...candidates].sort((left, right) => left.priority - right.priority);
}

const fallbackProviders = sortByPriority(
  providers.filter((provider) => provider.selection === "fallback")
);

const candidates =
  modelSelection === "auto"
    ? sortByPriority(providers)
    : modelSelection === "fallback"
      ? fallbackProviders
      : [
          ...sortByPriority(
            providers.filter((provider) => provider.selection === modelSelection)
          ),
          ...fallbackProviders
        ];
```

并把错误聚合保留为：

```ts
errors.push(
  `${provider.provider}: ${error instanceof Error ? error.message : "Unknown error"}`
);
```
