# 英伟达优先模型路由与临时选择 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为当前项目建立“英伟达优先，失败后系统兜底”的统一模型路由层，并在写作面板中支持每次临时切换模型。

**Architecture:** 先扩展环境变量与 AI 类型契约，再新增一个项目级 AI provider/router 层，把现有 JSON 模型调用统一收口。随后让 `writing-engine` 与 `/api/ai/assist` 走新路由，并在 `chapter-composer` 中加入默认可见的模型选择器与实际命中模型回显。

**Tech Stack:** Next.js App Router, React 18, TypeScript, Vitest, Zod

- [ ] **Step 4: 把 `src/lib/ai/client.ts` 改成底层调用工具**

保留 `extractJsonPayload`，新增底层调用函数：

```ts
export interface ChatMessage {
  role: "system" | "user" | "assistant";
  content: string;
}

export interface JsonModelCallOptions {
  baseUrl: string;
  apiKey: string;
  model: string;
  temperature: number;
  topP: number;
  messages: ChatMessage[];
  chatTemplateKwargs?: Record<string, unknown>;
}

export async function invokeJsonChatModel(options: JsonModelCallOptions) {
  const response = await fetch(`${options.baseUrl.replace(/\/$/, "")}/chat/completions`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Authorization: `Bearer ${options.apiKey}`
    },
    body: JSON.stringify({
      model: options.model,
      temperature: options.temperature,
      top_p: options.topP,
      messages: options.messages,
      chat_template_kwargs: options.chatTemplateKwargs
    })
  });

  if (!response.ok) {
    throw new Error(`Model request failed with status ${response.status}.`);
  }

  const data = (await response.json()) as {
    choices?: Array<{ message?: { content?: string } }>;
  };

  const content = data.choices?.[0]?.message?.content;

  if (!content) {
    throw new Error("Model response is empty.");
  }

  return extractJsonPayload(content);
}
```

- [ ] **Step 5: 创建 `src/lib/ai/router.ts`**

写入统一 JSON 路由：

```ts
import { invokeJsonChatModel, type ChatMessage } from "@/lib/ai/client";
import { getOrderedProviders } from "@/lib/ai/providers";
import type { ModelSelection } from "@/lib/ai/types";

export async function callRoutedJsonModel({
  messages,
  modelSelection
}: {
  messages: ChatMessage[];
  modelSelection: ModelSelection;
}) {
  const providers = getOrderedProviders();
  const candidates =
    modelSelection === "auto"
      ? providers
      : providers.filter((provider) => provider.selection === modelSelection);

  if (candidates.length === 0) {
    throw new Error("Unknown model selection.");
  }

  const errors: string[] = [];

  for (const provider of candidates) {
    if (!provider.apiKey) {
      if (modelSelection === "auto") {
        errors.push(`${provider.selection}: missing configuration`);
        continue;
      }

      throw new Error(`Model ${provider.selection} is not configured.`);
    }

    try {
      const payload = await invokeJsonChatModel({
        baseUrl: provider.baseUrl,
        apiKey: provider.apiKey,
        model: provider.model,
        temperature: provider.temperature,
        topP: provider.topP,
        messages,
        chatTemplateKwargs: provider.chatTemplateKwargs
      });

      return {
        payload,
        meta: {
          requestedModel: modelSelection,
          resolvedProvider: provider.provider,
          resolvedModel: provider.model,
          usedFallback: provider.selection === "fallback"
        }
      };
    } catch (error) {
      if (modelSelection !== "auto") {
        throw error;
      }

      errors.push(
        `${provider.selection}: ${error instanceof Error ? error.message : "Unknown error"}`
      );
    }
  }

  throw new Error(`All model providers failed. ${errors.join(" | ")}`);
}
```

export async function runWritingAssist(input: WritingAssistInput): Promise<WritingAssistResponse> {
  if (!isAiConfigured) {
    return {
      ...buildFallbackResponse(input),
      meta: {
        requestedModel: input.modelSelection,
        resolvedProvider: "fallback",
        resolvedModel: "local-fallback",
        usedFallback: true
      }

  try {

      meta: {

}
