# 全链路改版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把首页、新建页、项目总览页、写作页整理成“AI 带着走 + 中引导”的清晰主线，让用户始终知道自己现在在做什么、下一步该去哪里。

**Architecture:** 方案不做大规模重构，优先沿用现有页面与组件，在关键节点补上“主按钮 + 当前步骤 + 推荐下一步”的统一结构。交互上通过少量新的纯函数和提示卡片收敛文案与流程判断，避免把逻辑散在多个页面里。整体按页面主线分 5 个任务推进：入口页、建书页、总览页、写作页、导航与文案统一。

**Tech Stack:** Next.js 14、React 18、TypeScript、Vitest、现有 server component 页面、现有 client component 表单与写作组件

- [ ] **Step 4: 新建统一的“下一步推荐”逻辑**

```ts
export function getNovelNextStepSummary(input: {
  chapterCount: number;
  entityCount: number;
  outlineCount: number;
}) {
  if (input.entityCount === 0) {
    return {
      title: "推荐你现在先补关键人物",
      description: "先补 2 到 3 个关键人物，后面生成图谱和开始写都会更顺。",
      ctaLabel: "去补人物",
      href: "world"
    };
  }

  if (input.outlineCount === 0) {
    return {
      title: "推荐你现在先整理前几章结构",
      description: "不用一次写完整本，先把前 3 章理顺就够了。",
      ctaLabel: "去整理结构",
      href: "outline"
    };
  }

  if (input.chapterCount === 0) {
    return {
      title: "现在可以开始第一章",
      description: "核心信息已经够用了，先开写，后面再慢慢补。",
      ctaLabel: "进入第一章",
      href: "write"
    };
  }

  return {
    title: "继续推进下一章",
    description: "你已经有基础设定和内容了，推荐继续往下写。",
    ctaLabel: "继续写作",
    href: "write"
  };
}
```
