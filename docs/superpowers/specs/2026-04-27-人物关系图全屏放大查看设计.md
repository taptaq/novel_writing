# 人物关系图全屏放大查看设计

日期：2026-04-27

范围：
- 为图谱页增加 `放大查看` 入口
- 提供全屏弹窗式关系图查看态
- 在放大态中提供轻量说明信息
- 在放大态中保留节点点击查看关系能力

目标：
- 让用户在不离开当前图谱上下文的前提下，更清楚地查看复杂关系图
- 保持“看图优先”，说明信息只做辅助
- 不把放大查看做成新的独立工作台

## 1. 设计方向

本期采用：
- `全屏弹窗`
- `顶部轻信息栏`
- `右下角轻详情卡`
- `主图与放大态共享状态`

不采用：
- 新开独立页面
- 厚重侧栏详情
- 放大态中增加额外编辑能力
- 放大态中增加第二套筛选表单

核心原则：
- 放大查看是同一张图的沉浸查看态
- 图最大，信息最轻
- 点击后能看懂，但不打断读图

## 2. 结构设计

放大查看由三部分组成：

- `入口按钮`
  - 放在当前图谱页中间画布区域
  - 文案为 `放大查看`
- `顶部轻信息栏`
  - 作品名
  - 当前显示范围
  - 当前选中节点名（若存在）
  - 操作提示：`滚轮缩放，拖动画布移动，点击节点查看关系`
  - `关闭` 按钮
- `右下角轻详情卡`
  - 默认不显示
  - 当用户点击节点时出现
  - 仅展示轻量信息

## 3. 交互设计

### 3.1 打开方式

- 用户点击 `放大查看`
- 进入全屏弹窗
- 背景压暗
- 主关系图尽量占满可用空间

### 3.2 状态同步

主图与放大态共享同一份状态：
- 当前筛选范围
- 当前选中节点
- 当前高亮关系

设计要求：
- 若主图中已选中某节点，进入放大态后保留该状态
- 若放大态中切换了选中节点，回到主图后继续保留
- 关闭放大态后，不清空当前查看状态

### 3.3 放大态中的图谱行为

保留：
- 缩放
- 平移
- 点击节点高亮

不保留：
- 节点拖拽
- 图上编辑

### 3.4 关闭方式

支持三种关闭路径：
- 点击右上角 `关闭`
- 键盘 `Esc`
- 点击遮罩空白区

## 4. 轻信息设计

### 4.1 顶部信息栏

顶部栏只保留必要信息：
- 作品名
- 当前显示范围
- 当前选中节点名（如果有）
- 一句操作提示
- 关闭按钮

不展示：
- 大段关系说明
- 大段帮助文案
- 多层操作区

### 4.2 右下角轻详情卡

节点被选中后，右下角显示一张轻量卡片，内容为：
- 节点名
- 节点类型
- 一句简介
- `1 到 3` 条关键关系

卡片定位原则：
- 不遮住图中心
- 尺寸克制
- 重点是“看一眼就懂”

## 5. 技术实现建议

建议在现有 `GraphWorkspace` 基础上做增量实现：

- 在 `GraphWorkspace` 中新增放大态开关
- 复用现有图谱筛选与选中状态
- 复用现有 `GraphCanvas`
- 通过额外容器样式切换主图 / 全屏图的展示尺寸

建议新增或拆分的单元：
- `GraphFullscreenDialog`
  - 负责遮罩、关闭、顶部信息栏、右下角详情卡
- `GraphCanvasInfoBar`
  - 负责顶部轻信息栏
- 轻详情卡可直接内嵌在全屏组件中，首版无需过度拆分

## 6. 第一版边界

本次明确包含：
- 放大查看按钮
- 全屏弹窗
- 顶部轻信息栏
- 右下角轻详情卡
- 与主图共享选中与筛选状态

本次明确不包含：
- 放大态里的二次导出入口
- 放大态里新增复杂设置
- 放大态中额外的关系编辑
- 全屏态中的历史记录或对比模式

## 7. 测试建议

建议覆盖：
- 图谱页出现 `放大查看` 按钮
- 打开后出现顶部信息栏
- 选中节点时出现轻详情卡
- 关闭后当前状态保留
- 放大态不恢复节点拖拽

## 8. 实施顺序

建议按下面顺序落地：

1. 增加放大态状态管理
2. 增加全屏弹窗壳子与关闭交互
3. 接入顶部轻信息栏
4. 接入右下角轻详情卡
5. 补测试与回归验证
